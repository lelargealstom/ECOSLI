MeQ Produit — algorithme de décision

Le MeQ mesure la complétude d'une fiche produit dans le référentiel SLI. Le dénominateur — le nombre de champs attendus — varie selon le contexte de la fiche : consommable ou réparable, avec ou sans cycle préventif. L'arbre ci-dessous montre les 9 cas terminaux possibles, du minimum (3 champs) au maximum (19 champs).

MeQ = champs remplis / champs attendus × 100
Motif NA Motif Préventif Node Type

Arbre de décision — 3 questions, 9 issues

Les champs comptés dans le MeQ (rappel)

Base — toujours attendue DTR · Désignation · Node Type (3 champs)
